Adaptive vs. Fixed Readout in Neutral-Atom Arrays

A toy model of fluorescence readout in a neutral-atom array. It compares a fixed exposure against adaptive readout, which accumulates evidence frame by frame and decides each site as soon as it is confident.

By Ramsey Noah, September 2026. Modeling choices and conclusions are my own; the code was written with an AI coding assistant.

How long sites take to decide

What the model says

Early stopping cuts the average. Bright atoms announce themselves within a few photons, but a dark atom can only be confirmed by photons that never arrive, so dark sites set the pace.

An array waits for its slowest site. Decision times have a long tail, and in a globally imaged array the next step cannot start until every site is done. The average speedup mostly disappears at the array level unless decided sites can be released individually, for example by switching off their light to cut heating.

Splitting the exposure into frames only helps if atoms change state during imaging. Without that, the summed photon count already carries all the information, and every extra camera read adds noise.

Everything on this page scales with the detected photon rate. Doubling collection efficiency roughly halves every time shown here, which is why optics, not decision logic, is where large speedups live.

Model assumptions: Poisson photon counts, Gaussian camera read noise on every frame, independent sites, equal numbers of bright and dark sites, and no atom loss or depumping during imaging. The fixed window uses a single camera read with the best possible threshold. Default values are illustrative and are not taken from any lab's apparatus. Each run simulates 8,000 bright and 8,000 dark sites.
